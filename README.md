> "Aku tahu bikin logbook itu capek, makanya aku buatin ini khusus buat kamu. Biar kamu nggak perlu pusing lagi ngurusin format, dan bisa lebih banyak waktu buat istirahat... atau mikirin aku. Hehe. Semangat terus ya sayang! 💕"

Website mungil ini aku coding khusus buat memudahkan pembuatan logbook KKN, PLP, dan Asistensi Mengajar kamu. Semuanya otomatis kesimpen, nggak ribet, dan tinggal di-export.

## ✨ Kenapa Ini Spesial Buat Kamu?

- 🎀 **Semua Template Ada**: Mulai dari KKN, PLP, sampai AM. Tinggal pilih yang kamu butuhin.
- 💾 **Anti Hilang (Auto-Save)**: Tenang aja, datanya otomatis tersimpan di browser kamu. Jadi kalau ketiduran pas ngetik, besoknya masih ada.
- 📄 **Tinggal Download**: Selesai ngetik? Langsung export ke Word atau PDF. Rapi, siap kumpul!
- 🎨 **Cantik (Kayak Kamu)**: Tampilannya sengaja dibikin modern dan gampang dipake biar mata kamu nggak capek liatnya.
- 📱 **Bisa Dibuka di Mana Aja**: Mau pake HP pas lagi di jalan, atau pake laptop di kamar, semuanya lancar.
- 🔒 **Privasi Terjaga**: Nggak ada database server yang nyimpen data kamu. Semuanya aman di perangkat kamu sendiri.

## 🚀 Dibuat Pakai Apa? (Buat Ayang Kalau Mau Tau Aja)
Walaupun yang penting buat kamu itu hasilnya, tapi ini sedikit *behind the scenes* teknologi yang aku pake:
- **Jantungnya**: Next.js 14 & TypeScript
- **Bedaknya (Styling)**: Tailwind CSS
- **Pernak-pernik**: shadcn/ui & Radix UI
- **Rumahnya (Hosting)**: Vercel

## 🎯 Cara Pakainya Gampang Banget!

1. **Pilih Template** 📝 
   Buka websitenya di [sini](https://aisyah-logbook.vercel.app/), lalu pilih template yang lagi kamu kerjain.
2. **Isi Data Diri** 👤
   Masukkan nama kamu, NIM, dan pekan ke berapa.
3. **Mulai Nulis!** ✍️
   Klik "Tambah Entry", ceritain kegiatan kamu hari itu, tambah foto kalau ada.
4. **Isi Ringkasan (Buat PLP & AM)** 📊
   Jangan lupa isi total jam, analisis, hambatan, dll di bagian paling bawah.
5. **Download & Beres!** 🎉
   Klik export ke Word atau PDF. Voila! Logbook kamu siap dikirim ke dosen.

## 💡 Pesan dari Developer (Alias Pacarmu)

- 💾 Nggak perlu cari tombol save ya, biarin aja dia nge-save sendiri setiap 2 detik. 
- 📸 Kalau fotonya kebesaran, tenang, otomatis aku kompresin kok biar nggak berat.
- 🧹 **PENTING**: Jangan sering-sering clear cache browser ya sayang, nanti datanya bisa hilang. Kalau udah selesai, mending langsung export aja.
